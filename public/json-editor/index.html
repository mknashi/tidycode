JSON Editor Online

Open a JSON file, find your way around it, change it and save it. Tidy Code gives you a code editor with a structure tree beside it, tabs and split view for working across files, and conversion to YAML, XML and TOML, all in your browser.

Open the JSON editor

Find Your Way Around Nested JSON

The Structure panel shows your JSON as a tree of objects, arrays and values. In the default aligned layout, each row sits beside the line it describes, closing brackets included, so the tree scrolls with the code. Switch to the compact layout when you want a plain outline instead.

Click a row to select its line in the editor, and collapse the branches you don't need. The tree stays visible while you type, even while the JSON is briefly invalid in the middle of an edit.

Work Across Files

Tabs and split view

Open several JSON files at once, each in its own tab, and use Split to put two side by side, for example a config file and the sample it's based on.

Compare two versions

Diff shows two versions next to each other with the changes highlighted, which is useful for checking what an edit, a conversion or an AI fix actually changed.

VIM mode

Turn on VIM in the toolbar to edit with VIM keybindings.

Your work stays put

Open tabs and their contents are kept in your browser, so they're still there when you come back. Use Save to write the file itself.

Convert JSON to YAML, XML or TOML

Choose Convert → Convert to YAML (or XML, or TOML) to turn the open JSON into another format. A service config, converted to YAML:

JSON

{
  "service": "api",
  "port": 8080,
  "replicas": 2,
  "env": {
    "LOG_LEVEL": "info",
    "CACHE": true
  },
  "hosts": [
    "api-1.internal",
    "api-2.internal"
  ]
}

YAML

service: api
port: 8080
replicas: 2
env:
  LOG_LEVEL: info
  CACHE: true
hosts:
  - api-1.internal
  - api-2.internal

Check a converted file before using it. Not every structure maps exactly between formats; TOML, for example, has no null.

Large JSON Files

In the browser, Tidy Code opens JSON files up to 50 MB, using WebAssembly to index and search them. Above 100 KB, automatic formatting and the structure tree are off by default so typing stays responsive. You can turn the tree on for a file when you need it.

How to Edit a JSON File

  • Click Open the JSON editor, then open a .json file or paste JSON into the new tab
  • Show the Structure panel to see the tree beside the code
  • Click a tree row to jump to that part of the file, then edit
  • Use Format to tidy the indentation, or to convert to another format
  • Choose Save to write the file

Just need to pretty-print or validate a snippet? The JSON Formatter page covers formatting, error messages and what formatting changes.

Explore Nested JSON as a Graph

A catalog with a books array is easier to inspect when you can follow the relationships from the catalog to each book. Paste this valid JSON, then click Graph beside Structure:

{
  "catalog": {
    "name": "Weekend reading",
    "books": [
      {"title": "The Secret Garden", "author": "Frances Hodgson Burnett", "available": true},
      {"title": "Treasure Island", "author": "Robert Louis Stevenson", "available": false}
    ]
  }
}

Follow the catalog → books → individual book cards. Compare each title and availability value without searching through braces. Collapse branches to focus on one part, pan or zoom to explore, and use Fit to view to restore the overview. Export as PNG or SVG to share the structure.

The graph needs valid JSON. If a missing comma prevents it from opening, use the JSON repair walkthrough first. Very large structures may exceed graph limits even when the file can be edited.

Frequently Asked Questions

Can I edit large JSON files online?

Yes. In the browser, Tidy Code opens JSON files up to 50 MB, using WebAssembly for indexing and search. Above 100 KB, automatic formatting and the structure tree are off by default to keep editing responsive, and you can turn the tree on per file.

How do I find my way around deeply nested JSON?

Show the Structure panel. It lays the JSON out as a tree beside the code, with each row next to the line it describes. Collapse branches you don't need, and click a row to select its line in the editor.

How do I compare two JSON files?

Open both and use Diff in the toolbar. It shows the two versions side by side with the differences highlighted.

Will I lose my edits if I close the tab?

Open tabs and their contents are kept in your browser, so they're there when you come back on the same browser. To keep a copy outside the browser, use Save to write the file.
