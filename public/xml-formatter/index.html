How to Format XML

  • Open Tidy Code in your browser — no installation or signup needed
  • Paste your XML into the editor or drag and drop an .xml file
  • Valid pasted XML formats automatically where safe; use Format for manual formatting
  • Use the Structure panel to explore your XML as a tree
  • Click Convert to transform XML to JSON, YAML, or TOML

Repair XML Before Formatting

For example, <catalog><book>Garden</catalog> is missing a closing book tag. If you intended the book to contain Garden, the corrected document is:

<catalog>
  <book>Garden</book>
</catalog>

Use the error panel to locate the mismatch, then correct it manually or click Fix XML to try local rules. A repair is not guaranteed: inspect the proposed diff for element nesting, attributes, and text before accepting it. Replace current tab supports Undo; Open in new tab preserves the original. Accept All Changes formats the accepted document where safe.

Gemini Nano XML repair is not enabled. If local rules cannot fix the document, optional cloud repair requires clicking a named provider and sends the original document to it. Uncheck Use AI if rule-based fixing fails to use only local rules.

When Whitespace Matters

Automatic paste formatting leaves mixed content, xml:space, CDATA, and DOCTYPE documents untouched. For example, spacing around the emphasized word in <p>Read <em>this</em> carefully.</p> can be meaningful. Keep the original and review formatting changes before using the result.

After syntax errors are resolved, use the XML graph walkthrough to inspect element relationships.

Frequently Asked Questions

How do I format XML online?

Paste your XML into the Tidy Code editor and it will be automatically formatted with proper indentation and syntax highlighting. You can also click the Format button or press Ctrl+Shift+F to beautify your XML.

Does the XML formatter validate my XML?

Yes. Tidy Code automatically validates your XML as you type, highlighting syntax errors such as unclosed tags, mismatched elements, and malformed attributes with exact line numbers.

Can I convert XML to JSON or YAML?

Yes. Tidy Code supports converting XML to JSON, YAML, and TOML formats with a single click. The conversion preserves element hierarchy, attributes, and text content.

Is the XML formatter free?

Yes, Tidy Code's XML formatter is completely free with no signup required. Document editing and formatting run locally in your browser. If you choose a cloud AI feature, the content you submit is sent to that provider.
